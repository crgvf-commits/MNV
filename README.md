# MNV Layered Taxonomy

Machine-readable taxonomy definitions accompanying the paper
"Toward a Layered Taxonomy for Interoperable Cyber Threat
Intelligence Sharing."

## Files

- `mnv-core.json`: core classificatory area
- `mnv-norm.json`: normalization area
- `mnv-context.json`: complementary descriptive area
